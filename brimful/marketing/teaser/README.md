# Brimful sneak peek (9:16, 20 s)

`brimful-sneak-peek-20s.mp4` is ready for Reels, TikTok and Shorts (1080×1920, 30 fps, −14.1 LUFS, peak −2.3 dBFS).

To change a scene: edit `film.html` (each `scene(...)` block is one beat), then from this folder:
`python3 render.py film.html --audit` and `python3 render.py film.html --render video_noaudio.mp4`.
The sound needs the music track (see CREDITS.md) and earshot; `cues.json` lists every sound cue.
